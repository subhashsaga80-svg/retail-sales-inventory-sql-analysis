# Retail Sales and Inventory Analysis Using SQL

## Project Overview
This project analyzes retail sales, customer purchasing behavior, product performance, and inventory levels using SQL. The objective was to identify sales trends, high-performing products, valuable customers, and inventory risks.

## Business Objectives
- Understand customer purchasing patterns for targeted marketing.
- Evaluate product performance to support sales and stock decisions.
- Identify sales trends and improvement opportunities.
- Monitor inventory levels to reduce stock-outs and excess inventory.

## Tools Used
- MySQL / SQL Server
- SQL
- Excel / Power BI
- GitHub

## Dataset
The project uses a sample retail dataset containing customer, product, sales information.

## Key Analysis Performed
- Monthly and yearly sales trend analysis
- Top-selling products and categories
- Customer segmentation based on purchase value
- Region-wise sales performance
- Low-stock and overstocked product identification
- Revenue contribution by product category
- Ranking products using SQL window functions

## Key Insights
- Identified the highest-revenue product categories.
- Identified the products performed well in terms of sales and which are not.
- Identified the patterns in customer behavior, including repeat purchases and loyalty indicators, is critical for tailoring customer engagement strategies and improving retention rates.
- Found customer base segmentation. Effective segmentation is essential for targeted marketing and enhancing customer satisfaction .
- Found top customers based on total purchase value.
- Highlighted products with low inventory that may cause stock-outs.
- Identified slow-moving products that may require promotional action.

## Files in This Repository
- `database_schema.sql` - Tables and database structure
- `sales_analysis.sql` - Sales and customer analysis queries
- `inventory_analysis.sql` - Inventory-related queries
- `dataset/` - Sample dataset
- `screenshots/` - Query and dashboard screenshots
- `project_report.pdf` - Detailed project report

## How to Run
1. Create a database in MySQL or SQL Server.
2. Run `database_schema.sql`.
3. Import the sample dataset.
4. Run the SQL analysis files.
5. Review the output and dashboard screenshots.
